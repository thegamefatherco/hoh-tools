HoH Tools is a set of helpers for **Heroes of History**. It runs on the web and as a browser extension that opens in a side panel next to the game.

## Treasure Hunt

The negotiation helper recommends the best placement for every turn of a Treasure Hunt negotiation and tells you the exact chance of clearing it.
