The HoH Tools extension puts the [negotiation helper](/docs/treasure-hunt/negotiation) next to the game, so you do not have to switch tabs between turns. It is the same helper as on the web.

## Install

The extension is built for Chrome and Firefox. Each release attaches a Chrome and a Firefox zip to its GitHub Release; download the one for your browser and load it as an extension.

## Chrome and other Chromium browsers

The helper opens in Chrome's **side panel**.

- The toolbar button and the side panel are enabled only on game tabs (`heroesgame.com`). On other tabs the button is disabled and the panel closes.
- Click the toolbar button on a game tab to open the panel.

The extension only asks for access to `heroesgame.com` pages, to know which tabs are game tabs. It does not read or change the game.

## Firefox

Firefox has no side panel; the helper opens as a **sidebar** instead, which is available on every site.

## Appearance

The panel follows your system's light or dark mode.
